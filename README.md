# Aube

好きな YouTube 動画で起きられる、ブラウザの目覚まし時計です。

起きたい時刻と動画の URL を入れておくと、その時刻にページが YouTube へ切り替わって動画が再生されます。`index.html` 1 枚だけで動き、インストールもビルドも要りません。

## 使い方

1. `index.html` をブラウザで開く
2. 起きたい時刻（時・分）を選ぶ
3. 流したい YouTube 動画の URL を貼る
4. 「アラームをセット」を押す

あとは**タブを開いたまま**にしておけば、指定の時刻にタブが YouTube に移動して再生が始まります。

セット中は画面に「あと ◯時間◯分」のカウントダウンが出ます。時刻や動画を変えたいときはもう一度セットすれば上書きされ、「キャンセル」で解除できます。

設定はブラウザ（`localStorage`）に保存されるので、ページを閉じたり再読み込みしたりしても残ります。

### 使える URL

```
https://www.youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
https://www.youtube.com/embed/VIDEO_ID
https://www.youtube.com/shorts/VIDEO_ID
```

正しく読み取れると、入力欄の下に「動画を認識しました」と表示されます。

## 注意

- ページ内のタイマーで時刻を見ているだけなので、タブを閉じる・PC がスリープする・スマホの画面が消えるとアラームは鳴りません。
- バックグラウンドのタブはブラウザの省電力機能でタイマーが遅れることがあります。
- ブラウザの自動再生ポリシーによっては、YouTube 側で再生ボタンを押す必要があります。
- スヌーズはありません。
- 寝坊できない日は、スマホのアラームも一緒にかけておいてください。
