# Aube（オーブ）— 夜明けの目覚まし

指定した時刻になると、お気に入りのYouTube動画で目を覚ませる、シンプルな単一HTMLファイルの目覚まし時計アプリです。

## 概要

- ファイル: `index.html`（外部ライブラリ不要、Google Fontsのみ利用）
- 「夜明け前の空」をイメージしたダークテーマのデザイン
- ブラウザの `localStorage` にアラーム設定を保存し、ページを再読み込みしても設定が復元されます

## 主な機能

| 機能 | 説明 |
|---|---|
| 現在時刻表示 | 時:分:秒をリアルタイム表示（1秒ごとに更新） |
| 日付表示 | 年月日と曜日を表示 |
| アラーム時刻設定 | 時・分をプルダウンで選択（0〜23時 / 0〜59分） |
| YouTube URL 入力 | 通常のURL・短縮URL(`youtu.be`)・埋め込みURL・ショート動画URLに対応 |
| 動画認識表示 | 有効なURLを入力すると「動画を認識しました」と表示 |
| アラームセット/更新 | ボタン一つで設定・上書きが可能 |
| アラームバッジ | セット中は設定時刻と「あと◯時間◯分◯秒」のカウントダウンを表示 |
| キャンセル | 設定済みアラームを解除 |
| 発火時の動作 | 設定時刻になると、このページ自体が指定のYouTube動画URL（`autoplay=1`付き）に自動遷移 |

## 使い方

1. ブラウザで `index.html` を開く
2. 「アラーム時刻」で起きたい時・分を選択
3. 「YouTube URL」欄に目覚ましに使いたい動画のURLを貼り付け
4. 「アラームをセット」を押す
5. 設定時刻になると、開いているタブが自動的にそのYouTube動画に切り替わり再生されます

再設定したい場合は同じ手順で上書きでき、「キャンセル」ボタンでアラームを解除できます。

## URLの対応形式

以下の形式から動画IDを自動抽出します。

```
https://www.youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
https://www.youtube.com/embed/VIDEO_ID
https://www.youtube.com/shorts/VIDEO_ID
```

## データ保存の仕組み

アラーム設定は `localStorage` の `aube_alarm` キーに以下の形式で保存されます。

```json
{ "h": 7, "m": 30, "videoId": "xxxxxxxxxxx" }
```

ブラウザ・端末に紐づくローカル保存のため、他の端末やブラウザとは共有されません。

## 注意点・制限事項

- **タブを開いたままにする必要があります。** このアプリはページ内のJavaScriptタイマー（`setInterval`）で時刻をチェックしているため、タブを閉じる・ブラウザを終了する・スリープするとアラームは発火しません。
- **バックグラウンドでは動作を保証できません。** モバイル端末やPCの省電力機能により、バックグラウンドタブでは`setInterval`の実行が遅延・停止する場合があります。
- **発火は「現在のタブをYouTubeへ遷移」させる方式です。** 別ウィンドウでの再生やポップアップ表示ではなく、このページ自体がYouTubeのページに置き換わります。
- **音量・自動再生設定はブラウザに依存します。** ブラウザの自動再生ポリシーにより、`autoplay=1` が効かず手動再生が必要になる場合があります。
- **スヌーズ機能は未実装です。**（UIにスヌーズ/停止ボタン用のスタイルはありますが、現バージョンのHTML構造には対応するボタンは含まれていません）
- 確実な目覚まし用途（重要な予定など）には、スマートフォン標準のアラームアプリと併用することをおすすめします。

## カスタマイズのヒント

- 色味は `:root` 内のCSS変数（`--dawn-gold`, `--midnight` など）で調整可能
- フォントは Google Fonts の `Cormorant Garamond` と `Outfit` を使用
- `extractId()` 関数を編集すれば、対応するURLパターンを追加できます
